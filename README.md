# 每日一段 · DailyPassage

一个安卓桌面小部件：每天从小部件上读一段文字，点一下翻下一页，再点一下换一条。

内容来自《万维钢·现代思维工具100讲》，只取其中的 **核心模型** 字段，100 个工具各一条，共 **100 条**。不联网、不推送、不打扰。

---

## 一、它长什么样

```
┌──────────────────────────────┐
│ [思维工具]                    │
│ 1.4  硬约束                   │   ← 工具编号 + 工具名
│                              │
│ 硬约束是在当前问题尺度上无法   │   ← 正文（点一下翻下一页）
│ 靠意愿绕开的边界。课程强调四   │
│ 类：能量与资源守恒、时间窗口…  │
│                              │
│ 基本世界观      2/3  ↻ 换一条 │   ← 板块 / 页码 / 换一条
└──────────────────────────────┘
```

- **点正文区** → 翻下一页；到最后一页再点，回到第一页循环
- **点「↻ 换一条」** → 立刻换一条新的，页码归 1
- **每天 00:05 自动换一条**，同一天内内容恒定不变

## 二、怎么把它装到手机上

你这台电脑没有 Java / Android SDK / Gradle，本地编不出来。所以走**云端编译**，本机什么都不用装，只需要一个 GitHub 账号。

### 第 1 步：建仓库

浏览器打开 github.com，右上角 `+` → `New repository`。
仓库名随便（比如 `dailypassage`），**Public 或 Private 都行**，点 `Create repository`。

### 第 2 步：把本工程传上去

在工程根目录（就是有 `gradlew` 文件的那一层）打开命令行，依次执行：

```bash
git init
git add .
git commit -m "每日一段：首次提交"
git branch -M main
git remote add origin https://github.com/你的用户名/dailypassage.git
git push -u origin main
```

> 推送时会要求登录。GitHub 现在不收密码，需要 Personal Access Token：
> 头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，
> 勾上 `repo` 权限，把生成的 token 当密码填进去。

### 第 3 步：等云端编译

代码推上去后会自动开始编译。也可以手动触发：

仓库页面 → 顶部 `Actions` 标签 → 左侧 `Build APK` → 右侧 `Run workflow` 按钮 → 再点绿色的 `Run workflow`。

大约 3–5 分钟，等那条记录变成绿色对勾。

### 第 4 步：下载 APK

点进那次运行记录，页面拉到最下面 `Artifacts` 区域 → 下载 `DailyPassage-apk`。
它会是一个 zip，解开里面就是 `app-debug.apk`。

### 第 5 步：装到手机上

把 apk 传到手机（微信文件传输、数据线、网盘都行），点开安装。
系统会提示「不允许安装未知来源应用」，去设置里给对应的应用（文件管理器 / 浏览器 / 微信）放开权限即可。

### 第 6 步：把部件放到桌面

长按桌面空白处 → `小部件`（或`窗口小工具`）→ 找到 **每日一段** → 长按拖到桌面上。

建议拖成 **4×4** 大小（内容都是 100–214 字的长段，4×4 一页基本能装完一条）。拖大一点每页就装得多，分页会自动适配；嫌占地方也可以缩小，缩小后一条会分成两页，点一下翻页接着读。

## 三、装完之后必须做的两件事

不然「每天自动换」会失灵。这不是代码的问题，是安卓系统的限制。

### 1. 授予「精确闹钟」权限（Android 12 及以上）

打开 App「每日一段」→ 点 **精确闹钟** 按钮 → 在跳出的页面里允许。

### 2. 加入保活白名单

打开 App「每日一段」→ 点 **打开应用设置（保活）**，按 App 里写的各厂商路径设置。

各厂商大致路径：

| 品牌 | 路径 |
|---|---|
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 每日一段 → 省电策略选「无限制」，并允许自启动 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → 每日一段 → 关闭「自动管理」，三项手动全开 |
| OPPO / 一加 / realme | 设置 → 电池 → 应用耗电管理 → 每日一段 → 允许后台运行 |
| vivo / iQOO | 设置 → 电池 → 后台高耗电 → 允许每日一段 |
| 其他 | 设置 → 应用 → 每日一段 → 电池 → 选「无限制」 |

> 就算白名单没设全也不用太担心：每次点亮桌面、重启手机，小部件都会自己对一次日期，跨天了就自动换。最坏情况只是「准点换」变成「下次看手机时换」。

## 五、随机与分页是怎么做的

**随机 —— 洗牌队列。**
把 100 条内容打乱成一个队列，每天从队首取一条，取完再重洗。所以 100 天之内绝不会重复，而不是靠运气躲开重复。

**同一天内容恒定。**
以日期（如 `20261003`）作为状态锁，当天怎么刷新都是同一条，跨天才换。

**分页 —— 按实际尺寸算。**
小部件会读取自己在桌面上的真实宽高，估算每页能放多少字，再**往回找最近的标点符号**断句，避免把句子拦腰砍断。你把小部件拉大，每页就装得多。

## 六、想改内容怎么办

内容库是 `app/src/main/assets/pool.json`，100 条，长这样：

```json
[
  {
    "key": "1.1|核心模型",
    "id": "1.1",
    "board": "一、基本世界观（6）",
    "name": "叙事",
    "field": "核心模型",
    "text": "任何叙事都做了选择。它突出一些事实、忽略另一些事实……"
  }
]
```

- **想加内容** → 往数组里加对象，改完推回 GitHub 重新编译
- **想少一点** → 删掉不想要的条目
- **想换成别的字段** → 把 `field` 的值改掉即可（仅作标记用，不影响显示）

改完记得把 `key` 保持唯一，否则洗牌队列会串位。
